## 1. 测试概览

本次测试旨在评估分布式存储系统在中等负载下的性能表现，重点对比三种不同的认证数据结构 (ADS) 实现：
*   **MPT (Merkle Patricia Trie)**: 基于哈希的传统默克尔树。
*   **MEST (Merkle-based Search Trie)**: 基于哈希的搜索树变体。
*   **AccTrie (Accumulator Trie)**: 基于 RSA 累加器的加密树，支持无状态验证。

测试包含完整的生命周期操作：Add (插入), Query (查询), Update (更新), Delete (删除)，每种操作各 10,000 次，总计 40,000 次操作。

## 3. 详细性能分析

### 3.1 哈希 vs 累加器
*   **MPT / MEST**: 表现出极高的性能，吞吐量接近 900 ops/sec。这得益于 SHA256/Keccak 哈希运算的低计算成本。
*   **AccTrie**: 吞吐量约为 174 ops/sec。这是预期的结果，因为 RSA 累加器涉及大数模幂运算 (Modular Exponentiation)，其计算复杂度远高于哈希运算。AccTrie 用计算时间换取了更优的验证特性（如成员/非成员证明的大小恒定）。

### 3.2 并行化优化效果 (Rayon)
本次测试是在启用了 `rayon` 并行化优化后进行的。
*   **AccTrie 插入耗时**: 平均 **4.18 ms**。
*   **分析**: 单次 RSA 模幂运算通常需要 2-3ms。在树结构更新中，往往需要更新当前节点和兄弟节点/前驱节点。如果串行执行，耗时可能超过 8-10ms。当前的 4.18ms 表明并行化成功地将多个独立的加密运算分发到了多核 CPU 上执行，显著降低了操作延迟。

## 5. 结论

1.  **系统稳定性**: 在中等规模负载 (40,000 ops) 下，所有模式均保持 100% 成功率，系统运行稳定。
2.  **AccTrie 可用性**: 尽管吞吐量低于哈希结构，但 174 ops/sec 的性能对于许多需要强一致性和可验证性的分布式应用来说已经足够。
3.  **优化验证**: 并行化策略有效缓解了 RSA 运算的性能瓶颈，使 AccTrie 具备了工程实用性。
