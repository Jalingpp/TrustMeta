# 系统性能测试报告 (中等规模数据集)

**日期:** 2025年12月4日
**工作负载:** Medium (10,000 条记录, 共 40,000 次操作)
**系统:** 分布式存储系统
**测试的 ADS 模式:** MPT, MEST, AccTrie

## 1. 执行摘要

本报告总结了使用中等规模数据集 (10,000 个文件) 对系统进行的性能基准测试结果。

**主要发现:**
*   **吞吐量稳定性:** 即使数据量增加 10 倍，**MPT** 和 **MEST** 的吞吐量依然保持稳定，维持在 **856 ops/sec** 左右。
*   **AccTrie 性能:** **AccTrie** 的吞吐量为 **163.28 ops/sec**，与小规模测试结果 (158 ops/sec) 基本一致，说明其性能瓶颈主要在于计算密集型的证明生成和验证，而非数据规模带来的索引查找开销。
*   **证明大小:** 证明大小的特征与小规模测试一致，AccTrie 依然保持极小的证明尺寸。

## 2. 吞吐量对比

每次运行的总操作数: 40,000 (10,000次增加, 10,000次查询, 10,000次更新, 10,000次删除)。

| ADS 模式 | 吞吐量 (ops/sec) | 相对性能 |
| :--- | :--- | :--- |
| **MPT** | **856.68** | **100% (基准)** |
| **MEST** | 856.05 | ~99.9% |
| **AccTrie** | 163.28 | ~19.1% |

## 3. 延迟分析

### 3.1 证明生成时间 (微秒 - µs)

| 操作 | MPT (平均) | MEST (平均) | AccTrie (平均) |
| :--- | :--- | :--- | :--- |
| **增加 (Add)** | 376.58 µs | **304.56 µs** | 3327.69 µs |
| **查询 (Query)** | **78.87 µs** | 90.24 µs | 796.83 µs |
| **删除 (Delete)** | **86.57 µs** | 167.91 µs | 1029.55 µs |

### 3.2 证明验证时间 (微秒 - µs)

| 操作 | MPT (平均) | MEST (平均) | AccTrie (平均) |
| :--- | :--- | :--- | :--- |
| **增加 (Add)** | 7.09 µs | **5.52 µs** | 27.12 µs |
| **查询 (Query)** | 6.83 µs | **4.84 µs** | 1077.53 µs |
| **删除 (Delete)** | 4.12 µs | **0.29 µs** | 21.18 µs |
| **更新 (Update)** | 12.31 µs | **6.61 µs** | 51.66 µs |

## 4. 结论

在中等规模数据集下，系统的性能表现与小规模数据集高度一致。这表明当前的 ADS 实现具有良好的可扩展性，未出现因数据量增加而导致的性能急剧下降。

*   **MPT / MEST** 依然是高性能、高吞吐量的首选。
*   **AccTrie** 依然适用于对带宽极其敏感的场景，尽管其计算开销较大。
