# MPT vs MEST 操作性能对比报告

## 测试环境
- 操作次数：10000
- 操作类型：Add（插入）、Query（查询）、Update（更新）、Delete（删除）
- 统计指标：平均延迟、证明大小（字节）

---

## 主要性能数据

| 操作类型 | MEST 平均延迟 | MPT 平均延迟 | MEST 平均证明大小 | MPT 平均证明大小 |
|----------|--------------|--------------|------------------|------------------|
| Add      | 2.76 ms      | 3.61 ms      | 244,886 字节     | 249,071 字节     |
| Query    | 1.49 ms      | 1.34 ms      | 86,117 字节      | 87,052 字节      |
| Update   | 3.61 ms      | 3.44 ms      | 144,458 字节     | 256,384 字节     |
| Delete   | 3.11 ms      | 2.40 ms      | 129,739 字节     | 238,436 字节     |

---

## 详细分析

- **延迟**：MEST 在 Add 操作上更快，MPT 在 Query、Update、Delete 上略快。
- **证明大小**：MEST 在 Update 和 Delete 操作上显著优于 MPT，证明更小，节省带宽和存储。
- **所有操作均支持完整 Merkle Proof，可密码学验证。**

---

## 结论

- **MEST** 适合高频插入场景，且在数据变更（Update/Delete）时证明更紧凑。
- **MPT** 查询延迟略优，但在数据变更时证明较大。
- 两种模式均可满足高安全性需求，选择可根据业务场景权衡延迟与证明大小。
