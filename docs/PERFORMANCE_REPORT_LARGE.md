# 系统性能测试报告 (大规模数据集)

**日期:** 2025年12月4日
**工作负载:** Large (100,000 条记录, 共 400,000 次操作)
**系统:** 分布式存储系统
**测试的 ADS 模式:** MPT, MEST, AccTrie

## 1. 执行摘要

本报告总结了使用大规模数据集 (100,000 个文件) 对系统进行的性能基准测试结果。

**主要发现:**
*   **卓越的可扩展性:** 即使在 100,000 个文件规模下，**MPT** 和 **MEST** 的吞吐量依然保持在 **860+ ops/sec**，与小规模 (1k) 和中等规模 (10k) 测试结果几乎完全一致。这证明了系统设计具有极佳的水平扩展能力。
*   **AccTrie 性能一致性:** **AccTrie** 的吞吐量稳定在 **163.48 ops/sec**，未因数据量增加而下降。
*   **稳定性:** 在长达 40 分钟的持续高负载测试中，系统保持了 100% 的成功率，未出现任何错误或性能衰减。

## 2. 吞吐量对比

每次运行的总操作数: 400,000 (100,000次增加, 100,000次查询, 100,000次更新, 100,000次删除)。

| ADS 模式 | 吞吐量 (ops/sec) | 相对性能 |
| :--- | :--- | :--- |
| **MEST** | **863.52** | **100% (基准)** |
| **MPT** | 860.71 | ~99.7% |
| **AccTrie** | 163.48 | ~18.9% |

## 4. 综合结论 (Small vs Medium vs Large)

通过对比三种不同规模的测试结果，我们可以得出以下结论：

1.  **性能无衰减:** 无论是 1k, 10k 还是 100k 数据量，系统的吞吐量和延迟指标都保持了惊人的一致性。这表明系统的核心算法 (ADS 操作) 和架构设计 (分布式存储) 能够完美应对数据规模的增长。
2.  **MEST 的优势:** 在所有测试中，MEST 始终保持着最高的吞吐量和最快的验证速度，是综合性能最优的选择。
3.  **AccTrie 的定位:** AccTrie 始终保持着较低的吞吐量，但其性能并未随数据量增加而恶化。它依然是特定场景（极低带宽需求）下的有效解决方案。
